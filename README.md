# Bulk Certificate Generator

A simple browser-based bulk certificate generator for the recruitment task.

## Features
- Upload PNG/JPG certificate template
- Upload CSV/XLSX name list
- Live certificate preview
- Change font size, font family and text color
- Change X/Y position using sliders
- Drag the name directly on the preview
- Download a preview PNG
- Generate one combined PDF containing certificates for all names

## How to run
Open `index.html` in a browser.

The project uses SheetJS and jsPDF through CDN links, so an internet connection is needed when opening the page.
