# Section A: GDG AITR Portal Review & Suggestions

Website: https://gdgocaitr.vercel.app/

## Testing

## Mobile Review

Mobile and desktop views reviewed.

## Issues Found

### 1. Events Page
When the Hackathons filter is selected, "No events found" is displayed. A clearer message and an option to explore other events would improve the experience.

### 2. Event Registration
A past workshop displays that registration is closed, while also showing remaining seats. The registration status and seat availability could be presented more clearly.

### 3. Mobile Navigation
The fixed header takes up some screen space on mobile devices.

### 4. Team Page
Team member cards require considerable scrolling on mobile.

### 5. Contact Form
Clear validation messages and a success confirmation after submitting the form would improve usability.

### 6. Footer
The footer contains many sections and links, making it lengthy on mobile screens.

## Suggestions

- Show a helpful message when no events match a filter.
- Clearly distinguish event availability from registration status.
- Reduce the header height on mobile screens.
- Make team member cards more compact on mobile.
- Display clear form validation and submission confirmation.
- Improve footer spacing and navigation.

## Positive Points

- Attractive and consistent dark theme.
- Event details are organized into clear sections.
- Team members are displayed in profile cards.
- Contact information and form fields are easy to locate.

## Further Testing
Desktop review completed. The Home, Team, and Contact pages display correctly. The Hackathons filter shows "No events found", and copyright information is not visible in the footer.


## Desktop Review

### 1. Home Page
The heading, text, images, and cards are displayed properly on desktop.

### 2. Events Page
When the Hackathons filter is selected, "No events found" is displayed. This issue is also present on desktop.

### 3. Team Page
Team member photos, names, and cards are displayed properly on desktop.

### 4. Contact Page
Contact information and form fields are displayed properly on desktop.

### 5. Footer
